# docs

The domain model: the language the project speaks, the bounded contexts it is
split into, and why each is shaped the way it is. Not how the code works; that
belongs in comments and in each unit's `README.md`.

- [`domain/glossary.md`](domain/glossary.md) — the ubiquitous language.
- [`domain/context-map.md`](domain/context-map.md) — the bounded contexts and
  how they relate.
- [`domain/contexts/`](domain/contexts) — one document per bounded context.
  Copy [`_template`](domain/contexts/_template) for a new one.
